## Findings → fix quick map

| Finding                                                        | Fix                                                                                                                                                                              |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Node missing or older than 20                                  | Install Node.js 20+ before continuing.                                                                                                                                           |
| `pico-cli` not on `PATH`                                       | Public: `npm install -g @picoxr/pico-cli`; internal: team channel.                                                                                                               |
| `pico-cli` version needs review                                | Run `pico-cli update --check --format json`; when authorized, run `pico-cli update --yes --format json`.                                                                         |
| Unknown `pico-cli` command or option                           | Run help discovery; use only commands the installed CLI exposes.                                                                                                                 |
| Setup env is missing                                           | Run the setup command in `nextAction`; plugin commands do not initialize knowledge or platform dependencies.                                                                     |
| Host absent from the user level or the project                 | Run the explicit setup or project configure command in `nextAction`.                                                                                                             |
| Same-platform env-recorded plugin resources missing or drifted | Run the explicit setup or project configure command in `nextAction`, then rerun doctor.                                                                                          |
| Plugin installed but stale                                     | Run the explicit plugin update command in `nextAction`, then rerun doctor.                                                                                                       |
| Recorded version drifts from the loaded manifest               | Run the explicit plugin update command in `nextAction` to realign the recorded version, then rerun doctor.                                                                       |
| Host registry loads the plugin from a different path           | Run the explicit setup command in `nextAction`, use the Host's supported resource discovery/reconnect, then verify the loaded path and tools.                                    |
| Project platform mismatch                                      | Run the reported `pico-cli project configure` command and review the platform switch; do not combine cleanup and reinstall to switch the environment.                            |
| Source-channel handoff                                         | Run the reported setup command and review its complete transition plan.                                                                                                          |
| PICO development knowledge version mismatches project SDK line | Prompt the user to align, then run `pico-cli knowledge pull <major.minor>` followed by `pico-cli knowledge use <major.minor> --project <resourceRoot>` for the project SDK line. |
| MCP server absent or disconnected                              | Inspect Host authorization and registration, repair the confirmed gap, use supported discovery or reconnect, then verify tools.                                                  |
| Still broken after supported repair and reconnect              | Report the relevant doctor output and exact Host-visible error.                                                                                                                  |
