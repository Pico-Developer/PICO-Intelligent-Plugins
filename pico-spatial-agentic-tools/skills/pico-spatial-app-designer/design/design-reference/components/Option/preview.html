All components Option Guidelines

Option

Option supports selection and deselection. The page owns single- or multiple-choice rules, and the three groups below keep independent state.

Multiple choice

Select any number of options. Selecting an active option again clears it, including the last selection. The component keeps its default styling.

Single choice, optional

Plan recommendation · Page composition example using the component's default styling.

Select at most one option. Selecting another clears the previous option, and selecting the active option again clears the group. The initial state is empty.

Single choice, required

Plan recommendation · Page composition example using the component's default styling.

Keep exactly one option selected. Selecting another clears the previous option, while selecting the active option keeps it selected. Option A is selected by default.
