NumberField

Reference examples · original defaults unless explicitly overridden

Plan recommendation · quantity, weight and limits

These application examples set their own ranges, units and button steps. Use + / − to adjust, or type a value and leave the field to commit it. Out-of-range input is clamped to the nearest limit; the step controls button increments, not typed-value rounding.
