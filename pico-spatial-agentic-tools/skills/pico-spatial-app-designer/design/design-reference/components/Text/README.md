# Text

Text content with editable typography, color, alignment, wrapping and line limits.

## Web API
- `<sui-text>`: `text`, `text-style`, `color`, `text-align`, `soft-wrap`, `min-lines`, `max-lines`, `overflow`.
- Font and layout overrides reset to the selected typography role.
