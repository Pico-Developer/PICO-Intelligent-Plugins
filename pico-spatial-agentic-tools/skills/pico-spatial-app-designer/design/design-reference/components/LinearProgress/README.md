# LinearProgress

A horizontal bar for progress the screen reports. 240 wide, 4 high (Small, default) or 8 high (Regular). Track `fillTertiary`; indicator `labelPrimaryLight` (white). Round caps; the filled part is `fraction * (width - height) + height` wide, so a round end never leaves the track. Nothing is drawn at 0.

## Details
- The SDK has no indeterminate linear indicator. Use `CircularProgress` indeterminate for unknown duration.
- The white indicator needs a darker or colored backdrop. Override `progress-color` for light surfaces.

## When to use
- **Use for:** a known amount: download, upload, setup step.
- **Don't use for:** unknown duration (use `CircularProgress` indeterminate), a value the wearer sets (use `Slider`), page position (use `PageControl`).
- **Alternatives:** `CircularProgress` for compact or unknown waits.
- **Do:** pair it with a label that says what is progressing.
- **Don't:** animate it from 0 to 1 as decoration.

## Web API
- `<sui-linear-progress>` attributes: `value` (0 to 1), `size` (`small`, `regular`), `edge-style` (`flat`), `track-color`, `progress-color`. The element is 240 wide; set the host width to change it.

## Preview and shared rules

[Open this family’s preview](preview.html). The first section retains the Small/default 60% and Regular 30% examples with their default white indicators on the original darker backdrop, adding size/percentage labels.

The second section shows three static snapshots of the same download: waiting at 0%, downloading at 60%, and complete at 100%. Each includes a file name, status, percentage and an accessibly named progress bar. The completed example also uses `ic_check_circle`. Percentages correspond to `value` 0, 0.6 and 1; at 0 the track remains visible with no indicator fill. These examples explicitly set a dark `progress-color` for contrast on the light surface. They do not perform a real download or run a decorative progress timer.

The download bars explicitly fill the example width; the size comparison bars remain 240px wide when space permits and shrink on narrow screens. Component heights, track colors and cap styles retain their defaults. Completion text and icons are composed by the page, not generated by LinearProgress.
