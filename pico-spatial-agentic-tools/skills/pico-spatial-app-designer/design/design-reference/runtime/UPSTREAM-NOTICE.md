# Notice: what derives from the SDK

> **Draft.** The disclaimer text in this project (README.md, `site/disclaimer.html`, the page footers) and this notice have not been reviewed by the project owner. Have them reviewed before any external release.

This project contains no SDK source files. The icon assets below are shipped with the SDK and included as they are; the component glyphs in `src/glyphs.own.json` are drawn for this project as plain geometric strokes. The other parts carry values read from the SDK (Kotlin source and `res/values`) and should be reviewed before release.

| Part | What it carries from the SDK |
| --- | --- |
| `assets/icons/` (SVG and `catalog.json`) | ICON 7.0 as shipped with the SDK. |
| `project/tokens.json`, `tokens.css` | Color values and roles (`colors.xml`, `ColorScheme`), dimension tokens, type scale (`dimens.xml`, `typography.xml`), disabled alpha. Generated by `tools/gen_tokens.py` from a path given on the command line. |
| `project/color-roles.json` | The 16 theme color-role names, fallback token references and default Vibrant level mappings. No SDK source code is included. |
| `project/motion.json`, `motion.md` | Durations, bezier curves, spring damping and stiffness (`motion.xml`, `MotionTokens`), and the settle times and CSS curves sampled from them. |
| `src/parts/*.js` | Component dimensions, radii, paddings, gaps, text styles, color roles, spring and duration choices, and behavior rules (for example the page control window, slider geometry, tab bar sizes). Written independently as web code, but the numbers come from the Kotlin defaults. |
| `src/parts/*.js` strings | A few UI strings (for example the date picker title "Select Month" and its zh translation). |
| `tests/measure.html` | The expected sizes, one per Kotlin default. |
| `project/components/*/README.md`, `project/README.md`, `project/parity.md`, `ALIGNMENT.md` | Specs and facts described from the Kotlin source: sizes, colors by role, states, API names such as `ButtonDefaults.Small`. |
| `site-src/sdk_colors.json`, original upstream path "docs/coverage.md" (not shipped in this reference snapshot) | Generated by `tools/audit_params.py`: the default color role of every color parameter and the list of SDK parameters (names, types) checked against the Playground. |
| `site-src/components_live.py` (`PARAMS`) and `site-src/playground.js` | Names of Kotlin composables, defaults objects, parameters and enum values, used to generate the Kotlin snippets. |

Everything else (the web element implementation, previews, build scripts, the decision tables and "When to use" guidance) is original to this project.

Site layout (not derived from the SDK): the 1280x800 window size and the scale-to-fit behavior of the site shell are layout choices of this project.

Generated scene imagery in `assets/images` was created with the built-in imagegen tool; briefs are recorded beside the assets. `project/component-api.json` stores public API argument names/types used by the design explorer and includes no SDK implementation.
